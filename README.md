# Интеллектуальная справочная система по нормативным документам организации на основе технологии RAG
Это мой дипломный проект бакалавра. ГУАП 09.03.02 "Информационные системы и технологии", бакалавриат.

## Описание работы

**Тема**: Разработка интеллектуальной справочной системы по нормативным документам организации на основе технологии RAG

**Суть работы**: система позволяет сотрудникам и обучающимся задавать вопросы о внутренних правилах и регламентах организации на естественном языке и получать точные ответы со ссылками на конкретный документ и пункт. Для этого используется технология RAG (Retrieval-Augmented Generation): система сначала находит в базе документов фрагменты, наиболее близкие к вопросу по смыслу, а затем языковая модель формирует ответ строго на их основе. Это позволяет избежать недостоверных ответов и обеспечивает проверяемость информации. Апробацию системы планирую провести на корпусе локальных нормативных актов ГУАП (около 100–150 документов из открытых источников).

**Основные функции системы**:
- автоматический сбор документов и загрузка файлов через панель администратора;
- извлечение текста, разбиение на фрагменты и семантическое индексирование;
- вопросно-ответный веб-интерфейс или бот в мессенджере с указанием источников;
- сбор обратной связи пользователей о качестве ответов (дополнительно).

**Планируемые технологии (предварительный выбор)**:
- бэкенд: ```Node.js (Express)```;
- векторная база данных: ```Qdrant```;
- модель эмбеддингов: ```bge-m3``` (локально через ```Ollama```);
- языковые модели: ```GigaChat API```, а также локальная модель ```Qwen3``` для сравнения;
- развёртывание: ```Docker```.

## Текущая готовность
Сейчас идет разработка MVP. Уже готовы скрипты, вырезающие только текст из документов, без номеров страниц, титульников, фамилий подписантов и иного мусора. 
Также готово разбиение документов на чанки, эмбеддинг и выгрузка в локальный ```Qdrant```. Дальше по плану реализовать ответ пользователю от LLM.
В качестве LLM поставлю ```qwen3:4b-instruct```, а может даже ```qwen3:8b```, если мой комплюхтер его потянет. А еще протестирую облачный или тоже локальный ```GigaChat```.
После выполнения этого этапа можно считать, что MVP-шная версия программного RAG-ядра готова и для готовности полноценного MVP останется только запилить интерфейсик.
